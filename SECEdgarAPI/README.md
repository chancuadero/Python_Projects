📊 SEC Proxy Voting Comparison Tool
An interactive, production-grade data pipeline and web application that extracts, parses, and analyzes institutional proxy voting records (Form N-PX) directly from the SEC EDGAR system in real time.

Unlike standard scrapers, this tool dynamically crawls SEC submission directories to locate and extract machine-readable structured XML tables, bypassing the raw text and HTML wrapper limitations common in modern financial filings.
